## 未通过项与接受边界

**尚不能宣告全部生产验收完成。**

- 默认 WireGuard/Mutagen 同步仍间歇性 SSH 超时。实际会话和导出部分使用测试专用 SSH 转发，仍验证原密钥、forced-command 和在线授权；不替代默认 fclaude 启动/同步/退出验收。
- 部署任务领取后禁用账号，观察期间持续 preparing 并重领。后续移除测试安装才以 superseded 结束，不算禁用本身成功收敛。

自动回收两项缺陷已修复并通过生产回归。冲突解决修复保持 publication、attempt、输入摘要及 checkpoint 不变，仅接受 conflicted→published 的单向推进。

替代主机恢复按用户要求**免测并接受**，不标记为实际测试通过。
上一轮独立 SQL/内容恢复及 Node 归档恢复证据保留。
容量、磁盘不足、撤权、断电等历史专项结果继续有效，不冒充本轮重复实测。
