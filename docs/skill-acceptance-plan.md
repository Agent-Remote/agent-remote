## 验收边界与剩余项

**尚不能宣告全部生产验收完成。** 默认 WireGuard/Mutagen 同步多次出现 SSH 超时；
本轮实际会话 attach 和 Node 导出使用临时 SSH 转发，仍执行原有密钥认证、forced-command 和在线授权，
但不能替代默认隧道端到端流程验收。需要在默认连接恢复后补测正常 fclaude 启动/同步/退出闭环。

清理期间还观察到 Node 保留快照持续进入 recovery 重试，以及禁用测试账号后未完成部署继续等待。
本轮通过停服务后限定范围清理恢复环境，不将其记作 Node 自动回收通过；该生命周期路径仍需专项定位和验收。

本轮物理回收通过显式 `--all-unreferenced` 触发，不声称已等待 30/90 天验证自然到期。
协调备份验证了独立 SQL/内容恢复及 Node 归档恢复，不等同于在替代主机恢复旧运行时并启动真实模型的故障切换演练。
历史专项的容量、磁盘不足、撤权、断电和恢复测试继续有效，不将其冒充本轮重复实测。
